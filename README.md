Sum up 19 November 2026's world news in one image. A Python program draws a
newspaper front page: the first-ever three-way summit of Trump, Xi and Putin
in Shenzhen (a four-point "Declaration toward Peace", but no arms-control deal
and no mention of Ukraine or Iran), the ICJ ruling that Myanmar committed
genocide against the Rohingya, a suspected Houthi missile striking Riyadh's
PIF Tower, and Anthropic's record IPO on the Nasdaq — plus the day's other
news in an ALSO strip.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes one 1024×1024 PNG to `out/entry.png`. It needs no network
and is deterministic: two runs write the same bytes.
